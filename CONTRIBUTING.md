# Contributing

FLX Film Convert is a personal project, and its repository takes no issues or pull requests. It is
free software, though: you are welcome to fork it and change it under its licences.

## Building

Everything builds with the Command Line Tools on macOS 26 or later, on Apple silicon; see
*Building* in the README. `./build.sh cli` builds the command-line tool alone, and
`build/flxconvert --check-dyes SCAN --film STOCK` compares the GPU's dye split with the CPU's on a
scan of your own.

## Licences

A fork keeps the licences of what it builds on: the GPLv3 for the code and CC BY-SA 4.0 for the film
and paper data. The app icon is under neither, so a fork needs its own.
